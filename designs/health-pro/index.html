03 · Foundations

Surface & elevation

Depth is borders only. Cards, buttons, inputs and tables are flat with a border and carry no shadow. Only floating overlays — dropdown, popover, dialog, sheet, toast, tooltip — use a shadow, and always alongside a border.

border only — cards, buttons, inputs, tables

shadow-xs — reserved, unused by default

shadow-md — menus, popovers

shadow-lg — dialogs, sheets

Radius ramp — everything derives from --radius: 0.25rem

sm · 0px — buttons, inputs, cards, tables

md · 2px — unused

lg · 4px — unused

xl · 8px — unused

full · badges, avatars — the one exception

This is the boxiest design in the repository: buttons, inputs, cards and tables render with literally square corners (rounded-none). Only badges and avatars stay fully round.

04 · Primitives

Button

Six variants, four sizes. Square corners, uppercase, bold, tracked 0.05em — this is the single most identity-defining trait in the design. Default height is 40px (h-10). No drop shadow, ever.

Variants

Sizes

icon · h-10 w-10

States

Hover and active are shown statically here. No transform, no scale — targets never move.

With icons, button group & tag independence

Continue (as <a>)

The "Continue" button and its "Continue (as <a>)" neighbour share the exact class list and both carry data-slot="button" — this design keys no visual effect to the <button> tag, so a link that navigates renders identically to a button that acts.

14 · Navigation

Tabs & segmented control

Tabs are uppercase, tracked, and use a 2px underline — the same red as the active nav indicator, never the filled-pill treatment shadcn ships by default.

Horizontal tabs

The active panel renders below the bar with no additional container. A tab panel that adds its own border doubles the rule already drawn by the tab bar.

Segmented control

Vertical tabs

General Credentials Notifications Billing

Vertical tabs use the sidebar item treatment rather than an underline, because a vertical rule reads as a container edge.

24 · Composed

Feature grid — the action card

The signature pattern: a bordered, square-cornered card capped by a full-bleed CTA strip flush with the card's own edges — bg-sidebar-primary, h-11, centred uppercase label. Segmented by audience, mirroring how a professional body actually organises its site.

Each strip is a real <a href> carrying data-slot="button" — it navigates, so per shared/ACCESSIBILITY.md it is never a <button> styled to look like a link.
